## Hello World 만들기
러스트를 설치했다면 다음 명령어로 프로젝트 생성 가능하다.
```bash
# 프로젝트 생성
$ cargo new hello

# 프로젝트 이동
$ cd hello
```

실행은 다음과 같다. (디버그 모드 실행)
```bash
$ cargo run
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.00s
     Running `target/debug/hello`
Hello, world!
```

프로덕션 모드로 실행하려면 `--release` 옵션을 붙인다.
```bash
$ cargo run --release
   Compiling hello v0.1.0 (/home/gurumee/Workspaces/studies/00_project/RustInAction/ch01/hello)
    Finished `release` profile [optimized] target(s) in 0.18s
     Running `target/release/hello`
Hello, world!
Bavaria, Baden-Württemberg, Hesse
안녕 세상아
```
