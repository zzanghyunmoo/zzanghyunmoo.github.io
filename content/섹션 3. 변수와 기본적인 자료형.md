## 불리언 자료형과 조건문 if
* `std::boolalpha`를 이용해서 true / false 를 출력할 수 있다.
* `!A` 연산자로 A 반대 값으로 변경할 수 있다.
* `A && B`연산자는 A, B 모두 참이어야 참, 나머지는 거짓
* `A || B` 연산자는 A, B 하나라도 참이면 참, 둘 다 거짓이면 거짓
* `if (조건식)`으로 분기 처리할 수 있다.
	* 조건식이 참일 때 `{ ... }`이 실행된다.
* `if-else`에서 `else`는 조건식이 false일 때 실행된다.
* `if - else if - else` 문으로 여러 조건들을 실행할 수 있다.
* C++에서는 1은 true 0은 false이다. 정확히는 0이 false 나머지는 true
* `ctrl + r + r`로 스코프 내 변수 이름을 치환할 수 있다.
