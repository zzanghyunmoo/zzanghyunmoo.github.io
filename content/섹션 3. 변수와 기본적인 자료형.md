## 부동소수점수
* 부동소수점 타입
	* float 4byte
	* double 8byte
	* long double 8byte (플랫폼마다 가변적임)
* GPU 계산 시, float을 주로 사용함.
* `std::isinf`로 `inf`를 확인할 수 있다. ( +- 수 / 0 = +- inf)
* `std::isnan`으로 `nan`을 확인할 수 있다. ( 0 / 0 = nan)
