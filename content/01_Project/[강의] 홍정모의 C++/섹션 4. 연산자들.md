## 연산자 우선순위와 결합 법칙
* Precendence: 우선 순위
	* 우선순위가 낮을수록 더 높은 우선순위를 가진다.
* Associativity: 결합 법칙 
	* 동등 우선 순위일 때 어떤 것 부터 계산할 것인지 결정한다
	* 왼쪽 -> 오른쪽, 대부분 연산자들이 이 결합 법칙을 사용한다.
	* 오른쪽 -> 왼쪽, ++, +x, -x, sizeof, new, delete, ?:, +=, -=, = etc.. 자세한건 다음 [문서](https://en.cppreference.com/w/cpp/language/operator_precedence.html) 참조
* 우선순위가 헷갈릴 때는 `()` 묶어서 명확하게 우선순위를 표현하자.
## 산술 연산자
* +, -, *, /, %
* / 연산자는 정수 / 정수라면, 정수가, 실수 / 정수 혹은 실수 / 실수 하면 값이 실수가 나온다
## 증감 연산자
* ++, -- 
* ++x 는 연산이 먼저 진행된다.
* x++는 연산이 후에 진행된다.
* x=1, y=1일 때, `cout << ++x << " " << y++ << endl;`일 때, 2, 1이 출력된다. 식이 끝난 후, y도 2가 된다.
