## 프로그램의 구조

```cpp
#include <iostraem>

int main(void)
{
	// 표준 출력으로 "Hello World!를 출력하고 줄바꿈을 한다.
	std::cout << "Hello World!" << std::endl;
	return 0;
}
```

* 프로그램을 실행한다라는 것은 운영체제에게 프로그램을 실행시켜달라고 명령하는 것과 같다.
* 프로그램의 최소 단위는 "함수"이다.
	* 함수란? 
		* 입력을 로직에 따라 출력을 만드는 것.
		* 타입 이름 ( 함수 인자... ) { 명령어; return 타입에 맞는 값;}
 * main 함수는 매우 특별한 함수이다.
	* 프로그램 실행 시 운영 체제가 이 함수를 찾아서 실행한다.
	* 즉 프로그램의 진입점이다.
* ; 은 statement의 끝에 반드시 필요하다.
* expression 1 + 2;
* int x; 변수를 선언하는 것. 정수형 값을 받는 공간을 x라는 이름으로 선언하는 것.
* int x = 2; 라고 선언해도 x =5; 이렇게 변경할 수 있다.
* `#include<iostream>` 은 입출력 표준 라이브러리를 가져오는 것이다.
	* `#include`는 전처리기라고 부른다.
	* `iostream`은 입출력 하는 함수/객체들이 정의되어 있다.
	* 이 경우 네임스페이스 하위에 있는 함수/객체들을 `::` 가져올 수 있다
	* `std` 네임스페이스에 `std::cout`, `std::endl` 을 사용하여 콘솔에 값을 출력할 수 있다.

## 주석
* 주석이란?
	* `//`,. `/* */` 으로 주석을 달 수 있다.
		* 보통 `//`를 많이 한다.
* 컴파일러는 주석을 무시한다.
* 보통 메모할 때 주로 쓰인다.
* 미래의 나를 위해 주석을 달아서 메모하는 습관을 들여보자.
	* 헷갈릴 수 있는 건 반드시 남기자
	* 
* 보통 statement 위에 작성한다. 
## 변수와의 첫 만남

용어
* 객체: 메모리에 올라가서 저장되는 값
* 변수: 객체의 메모;리 주소의 이름
* L Value  / R Value: L Value는 변수, R Value는 값.
* 초기화 initialization: 변수 생성 후 처음 값을 저장하는 것. 
* 대입 assignment: 변수의 값을 저장하는 것. (= 연산자 사용)
* 초기화를 안했을 때의 문제점: C/C++의 경우 쓰레기 값을 갖게 되어 로직 오류를 일으킬 수 있음.

변수 선언과 대임
```cpp
int x;   // variable declaration
x = 123; // assignment
```

변수 선언과 동시에 초기화
```cpp
int x = 5;  // assignment
int y (10);
```

초기화를 하지 않고 빌드를 했을 때, 쓰레기 값이 초기화 된다. 또한 컴파일러가 Warnging을 표시해준다. (Release 모드는 기본 값을 넣어준다.)

참고 내용
* `&{변수 명}`은 변수의 주소를 가리킨다. 
* Debug, Release? 
	* Debug는 프로그램 개발 환경 빌드 실행
	* Release는 실제 프로덕션 환경 빌드 실행  -> 훨씬 빠름
## 입출력 스트림과의 첫 만남 cin, cout
* cin: 입력을 받는다.
* cout: 출력한다.
* endl: 개행을 해준다.

```cpp
int x = 1024;
double pi = 3.14;

std::cout << "x is " << x << std::endl;
std::cout << "pi is " << pi << std::endl;
std::cout << "abc" << "\t" << "def" << std::endl;
```

* `\t` 는 탭을 한다.
* `\n`과 `std::endl` 거의 동일하다.
* `using namespace std;`로 네임스페이스 구문을 넣으면 `cout` 이렇게 간단히 쓸 수 있다. (하지만 대부분 네임스페이스를 지정하는 것 같다.)

## 함수와의 첫 만남
* 함수: 작은 단위의 로직을 작성.
* 리턴 값: 함수의 반환 값.
* 파라미터: 함수에 전달되는 값
