## 불리언 자료형과 조건문 if
* `std::boolalpha`를 이용해서 true / false 를 출력할 수 있다.
* `!A` 연산자로 A 반대 값으로 변경할 수 있다.
* `A && B`연산자는 A, B 모두 참이어야 참, 나머지는 거짓
* `A || B` 연산자는 A, B 하나라도 참이면 참, 둘 다 거짓이면 거짓
* `if (조건식)`으로 분기 처리할 수 있다.
	* 조건식이 참일 때 `{ ... }`이 실행된다.
* `if-else`에서 `else`는 조건식이 false일 때 실행된다.
* `if - else if - else` 문으로 여러 조건들을 실행할 수 있다.
* C++에서는 1은 true 0은 false이다. 정확히는 0이 false 나머지는 true
* `ctrl + r + r`로 스코프 내 변수 이름을 치환할 수 있다.
## 문자형 char type
* 어떤 숫자가 어떤 문자인지 확인하려면 ASCII 테이블 참조해라.
* char의 값은 `''`을 이용한다. (문자열은 `""`)
* cin 후, abc 이런 식으로 문자열을 입력해버리면 버퍼에 문자가 여러 개 들어가서 원하는 결과가 안 나올 수 있다.
* escape 문자
	* \n, \0, \t 등등이 있다.
## 리터럴 상수 Literal Constants
* 상수에는 리터럴 상수와 심볼릭 상수가 있다.
* u, f, d, l, 0x, 0b 같은 것이 리터럴이라고 부름
## 심볼링 상수 Symbolic Constants
* `const [타입] [상수명]` 형태를 심볼릭 상수라고 함.
* 상수명은 대문자와 `_`로 구성함
* 선언 / 초기화 방법은 변수와 같지만, 초기화 이후 일반적인 방법으로는 값을 변경할 수 없다.
* 혹은, 함수 파라미터로 변경하지 말라는 의미로 const를 붙이는 것이 일반적이다.
* 컴파일 타임에 결정되는 상수와 런타임에 결정되는 상수가 있다.
	* c++11에서는 `constexpr` 키워드를 이용해서 컴파일 타임에 결정되는 상수들을 분리할 수 있다.
* c++에서는 `#define <매크로 변수 명> 값` 형태의 상수 선언은 사용하지 않는다.
